# 时空探索手札

面向华为平板的触控优先 PWA。用户在纸页上自由手写文史问题；Pi 在后台调用受控的 CNKGraph 寻迹工具，并以证据旁批、联想旁批和可收纳印章回应。

## MVP 交互原则

- 纸页是主界面，不出现聊天框或图谱主面板。
- 原笔迹永远保留；识别文本可见、可修订。
- 停笔后 1 秒内出现本地“识字中”反馈。
- 证据旁批与模型联想必须用不同墨色和标签区分。
- 点旁批词才打开寻迹卡；图谱只作为按需展开的证据层。

## 当前阶段

纸页手写、停笔苏醒、页边旁批、收为印章、翻页回看，以及三种寻迹结果已形成可录屏的离线纵切面。旧项目 `../shangtu` 只作为 CNKGraph 查询和来源追溯的只读参考。

离线演示不会伪装成真实模型结果：它使用仓库内置、带固定公开来源的 `李白 → 作者 → 将进酒` 子图夹具，只用于稳定排练。默认书写流程已接到受控服务端边界：Canvas PNG → `/api/transcribe` → 页边可编辑确认 → `/api/seek` → Pi。视觉或 Pi 未配置时，页面只显示明确的缺口说明，绝不生成伪造旁批。

## 本地预览

```bash
npm install
npm run dev -- --host 0.0.0.0
```

首次使用时，在华为平板浏览器中选择“添加到主屏幕”。PWA 壳会缓存纸页与基础资源；Pi、视觉识别与 CNKGraph 寻迹仍需要受控服务端。

### 稳定录屏入口

- `/?demo=evidence`：证据旁批、寻迹卡、来源与印章。
- `/?demo=ambiguous`：实体歧义与候选。
- `/?demo=gap`：证据缺口与明确标注的“联想”。

完整的三分钟真机验收见 [`docs/demo-recording.md`](docs/demo-recording.md)。

### 开发用全链路演练

不配置任何密钥时，可只在服务端开启下列夹具，排练“Canvas 截图 → 可编辑确认 → 已核验旁批”：

```bash
NOTEBOOK_FIXTURE_MODE=1 npm run dev -- --host 0.0.0.0
```

该模式不调用视觉模型、Pi 模型或网络；纸页会明确显示“演练转写（未调用视觉模型）”，并只使用仓库固定的 CNKGraph 演示来源。默认不启用，不能作为真实识别或生产回退。

## 验收分支

1. 成功寻迹：证据旁批、寻迹卡与来源。
2. 实体歧义：短旁批澄清并给出候选。
3. 证据不足：说明证据缺口；如有模型补充，显式标为“联想”。
