# MVP 合同

## 书页状态

`静读` -> `书写` -> `停笔反馈` -> `转写` -> `寻迹` -> `旁批` -> `收纳印章` -> `翻页回看`

停笔后 1 秒内，必须仅用本地状态进入 `停笔反馈`：墨迹呼吸、关系纹路起笔和“识字中”。网络或模型结果不能阻塞这一反馈。

切换到 `静读`、翻页、续页或重新落笔时，前端必须取消尚未完成的 OCR/Pi/联想请求；迟到响应不得改变当前纸页，也不得在静读期间继续占用寻迹 transport。

## 回应层级

| 层级 | 含义 | 纸面表现 |
| --- | --- | --- |
| 证据旁批 | CNKGraph 已支持的关系或结论 | 深色墨迹，可点开寻迹卡 |
| 联想 | 模型的文化补充，不构成事实 | 浅色墨迹，固定显示“联想” |
| 澄清 | 转写低置信度或实体不唯一 | 页边短批注，可改字或点候选 |
| 证据缺口 | 未找到可靠路径 | 页边短批注，不得伪装为答案 |

## Pi 工具边界

Pi 接收：当前页 ID、笔迹段 ID、用户确认前后转写、历史印章摘要。

Pi 输出：工具调用记录、状态短语、旁批、锚点关键词、证据引用、候选项或证据缺口。

浏览器不得直接持有 CNKGraph/API 凭据，也不得把模型联想写成事实层。

路线证据落纸后，纸面节拍按“起点 → 转折 → 回望 → 收束”推进，路线卡同时显示当前节拍的“线索提示”，告诉用户应写具体的地点、作品、事件或时间词；地点路线首笔可优先提示人物档案中的籍贯。第四条证据后提示用户收纳或继续写新的回声；点击“收纳这条路线”会把当前已核验的证据旁批统一收为印章，歧义和证据缺口仍留在纸面上，原始笔迹与寻迹卡仍可从印章恢复。前两条已核验路径先由纸页本地生成即时的非事实性联想；达到至少两条路径后，`/api/narrative` 才接收已核验的路径摘要与来源原文中的时间词，并要求该证据在服务端 15 分钟内的有界收据中存在，异步返回可选的“联想：”文本。模型可以利用自身的文学/历史常识寻找意象和追问方式，但不得把未在路径中出现的具体事实写入联想。模型未及时返回时保留本地底稿，联想服务失败、超时或未配置时不影响证据旁批、原始笔迹或下一笔。时间词只照录原文，不换算成年号或推断生平。

当纸页已有人物旅程时，“续页”继承该旅程的有界历史；人物锚点旁显示受限人物档案来源链接和标注为“档案摘录”的短片段。路线未定时，用户可以点选地点、经历或作品，也可以直接确认“地点线 / 经历线 / 作品线”作为路线选择；这时直接写另一个人名也不会静默替换锚点，必须先点按“换人物”。点按纸页上的“换人物”后，写下并确认新的精确人物名或唯一可确认别名会建立新的锚点；路线已定后，所有短地点/作品词仍属于当前路线，多候选别名不得静默选择，不覆盖旧页原始笔迹或旁批。摘录只来自人物档案，不把 LLM 生成的生平当作事实。

纸页底部的“清空”只重置当前页的笔迹、转写、旁批和人物旅程；清空前必须二次确认，其他页和翻页历史保持不变，且会取消当前尚未完成的 OCR、寻迹和联想请求。
