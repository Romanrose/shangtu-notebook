# MVP 合同

## 书页状态

`静读` -> `书写` -> `停笔反馈` -> `转写` -> `寻迹` -> `旁批` -> `收纳印章` -> `翻页回看`

停笔后 1 秒内，必须仅用本地状态进入 `停笔反馈`：墨迹呼吸、关系纹路起笔和“识字中”。网络或模型结果不能阻塞这一反馈。

## 回应层级

| 层级 | 含义 | 纸面表现 |
| --- | --- | --- |
| 证据旁批 | CNKGraph 已支持的关系或结论 | 深色墨迹，可点开寻迹卡 |
| 联想 | 模型的文化补充，不构成事实 | 浅色墨迹，固定显示“联想” |
| 澄清 | 转写低置信度或实体不唯一 | 页边短批注，可改字或点候选 |
| 证据缺口 | 未找到可靠路径 | 页边短批注，不得伪装为答案 |

## Pi 工具边界

Pi 接收：当前页 ID、笔迹段 ID、用户确认前后转写、历史印章摘要。

Pi 输出：工具调用记录、状态短语、旁批、锚点关键词、证据引用、候选项或证据缺口。

浏览器不得直接持有 CNKGraph/API 凭据，也不得把模型联想写成事实层。
