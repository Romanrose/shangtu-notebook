# 三分钟验收与录屏脚本

此文件服务于当前没有模型/API 凭据时的稳定排练。URL 参数只选择**离线演示夹具**，不是正式寻迹逻辑；正式版本会由视觉转写 + Pi 白名单工具替换。

1. 打开 `/?demo=evidence`：写“李白写过《将进酒》吗？”；停笔后应先在 1 秒内出现“识字中”，随后出现证据旁批、`联想` 旁批和印章。点按证据旁批，确认寻迹卡中有来源和 `李白 → 作者 → 将进酒`。
2. 打开 `/?demo=ambiguous`：写“李贺和长安有什么关联？”；停笔后确认只出现澄清旁批与两个候选，不会擅自选人。
3. 打开 `/?demo=gap`：写“珊瑚与唐诗有什么关联？”；停笔后确认出现证据缺口，补充内容明确标作 `联想`，没有伪造来源。
4. 切到“静读”写一笔：应只留下笔迹，不出现“识字中”或旁批。
5. 在 evidence 页点“收为印”：关系纹路淡去，仅留下页边印；再点印章应还原旁批和寻迹卡入口。

平板验收：在华为平板浏览器打开 PWA，横竖屏各写一次；确认触控笔与手指均可画、浏览器滚动不抢手势、停笔立即出现本地苏醒状态。
