# Three-branch acceptance matrix

| Case | User-visible proof | Required boundary |
| --- | --- | --- |
| Evidence found | Original handwriting remains; evidence annotation appears; selected word opens a trace card with a source and a bounded path. | Do not mix model association into the evidence annotation. |
| Ambiguous entity | A short margin clarification shows candidates or an editable transcription. | Do not select an entity silently. |
| Evidence gap | A compact margin annotation names the missing evidence; any optional model content is labelled `联想`. | Do not invent a source, date, relationship, or record. |

For all three cases, seek mode must show a local awakening state within one second of pen-up and quiet mode must not invoke Pi.
